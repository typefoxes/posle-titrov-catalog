# После титров: публичный Wiki-каталог

Публичные пакеты метаданных Wikidata / Wikipedia для приложения «После титров». Репозиторий не содержит пользовательского дневника, прогресса, фотографий, ключей, Firebase credentials или checkpoint импортера. Исходные репозитории приложения и автоматизации остаются отдельными.

Каталог пока проходит инфраструктурную проверку. Наличие пакета не означает завершённую миграцию приложения или готовность к релизу.

## Данные и происхождение

Структурированные сведения Wikidata распространяются на условиях CC0. Для каждого текста Wikipedia сохранены источник, ревизия, ссылка, атрибуция и фактическая лицензия в документе. Используйте указанные там условия; очищенный текст является производным от указанной статьи. Единой лицензии, заменяющей лицензии текстов, у всего пакета нет. Медиафайлы и чужие постеры в этот пакет не включены.

Текущий наблюдаемый охват: 559632 произведения, 212165 сезонов/эпизодов, 44587 сюжетов и 395091 публичный справочник. Это охват выбранных классов и связей Wikimedia, а не обещание полноты мирового кино. Неполные названия, связи и даты остаются неизвестными. Точные внешние ID сохраняются без слияния разных произведений.

## Адресное чтение

Releases используют тег `wiki-<packageSHA256>` и три файла: `catalog.json`, `catalog.index`, `catalog.pack`. Package SHA относится к каноническому JSON всего `catalog.json`, каталог источника имеет отдельный catalogSHA256. Приложение закрепляет тег, проверяет hash-directory и SHA каждого envelope, затем использует прежний bounded zlib codec. Чтение отдельных HTTP206 диапазонов не требует загрузки всего каталога. Индекс разбит на небольшие страницы по SHA; данные неизменяемы в пределах тега.

Последняя проверенная локальная версия и непустой кэш сохраняются при отсутствии сети, неполном обновлении или ограничении сервиса. Автоматического клиентского fallback на Firebase, Trakt или Кинопоиск для массовых новых чтений не предусматривается. Клиентская реализация и её проверки ещё выполняются отдельно.

## Бесплатная эксплуатация

Firebase Spark остаётся источником публичной публикации и закрытого состояния импортера. Массовые чтения планируются через эти публичные пакеты; персональные данные остаются на устройстве. Платные тарифы и Git LFS не подключаются. Обновление зеркала должно резервировать месячный бюджет чтений до обращения к Firebase и сохранять прежний release при незавершённой работе.

[GitHub Releases](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases) не имеет отдельной заявленной квоты bandwidth, но [Acceptable Use](https://docs.github.com/en/site-policy/acceptable-use-policies/github-acceptable-use-policies#9-excessive-bandwidth-use) допускает ограничение чрезмерной нагрузки. Неограниченная доступность и SLA не обещаются.
